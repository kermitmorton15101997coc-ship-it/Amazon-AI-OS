# 飞书知识库授权操作说明

## 当前配置状态

- 飞书 MCP 已安装到：`.codex/lark-mcp-runner-stable`
- 授权令牌存储目录已改到：`.codex/feishu-auth`
- 登录脚本：`.codex/mcp/login-feishu-user-oauth.ps1`
- 双击入口：`.codex/mcp/运行飞书用户授权.cmd`
- MCP 启动脚本：`.codex/mcp/start-feishu-lark-mcp.ps1`

## 必须先确认飞书开放平台设置

在飞书开放平台应用安全设置中，OAuth 重定向 URL 必须包含：

```text
http://localhost:3000/callback
```

如果没有配置，请到应用安全设置页面添加后发布/保存。

## 授权步骤

1. 双击 `.codex/mcp/运行飞书用户授权.cmd`。
2. 窗口会显示一个 `http://localhost:3000/authorize?...` 授权链接，并尝试自动打开浏览器。
3. 如果浏览器没有自动打开，复制该链接到浏览器。
4. 用有飞书知识库权限的账号登录并确认授权。
5. 页面显示 `success, you can close this page now` 后，回到窗口看到 `Successfully logged in` 即完成。

## 授权后启动 MCP

授权完成后，使用：

```powershell
$env:FEISHU_MCP_OAUTH="1"
powershell -ExecutionPolicy Bypass -File .\.codex\mcp\start-feishu-lark-mcp.ps1
```

## 常见问题

- 如果提示 redirect URL 未配置，去飞书开放平台添加 `http://localhost:3000/callback`。
- 如果提示 scope 未授权，需要在飞书应用权限管理里开通文档、知识库、云空间、搜索相关权限，并发布应用。
- 如果登录成功但搜不到知识库，需要确认授权账号本身能打开目标飞书知识库。
