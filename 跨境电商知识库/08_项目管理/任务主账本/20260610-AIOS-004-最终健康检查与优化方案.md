## 已完成加固

- 修复配置部署脚本误绑旧版本号的问题，改为动态校验候选版本。
- 部署脚本排除 `Amazon-AI-OS/` 镜像目录，并要求候选配置唯一，防止误部署备份副本。
- 补齐根目录 `.agentignore` 对同步知识库风险关键词的隔离覆盖。
- 验证器新增 `.agentignore` 受保护路径与关键词规则检查。
- 同步脚本的 `.agentignore` 生成模板同步加固，避免下次全量同步覆盖安全规则。

## 优化方案

| 优先级 | 动作 | 完成标准 | 建议负责人 |
|---|---|---|---|
| P0 | 完成飞书用户授权或知识空间授权 | 可读取一个指定文档，成功同步为 Markdown，并写入飞书同步日志 | 知识库管理员 |
| P0 | 完成四个业务试点 | 每个试点补齐真实脱敏输入，至少一个任务走完审批、验证、监控和回写 | 各试点 owner / 审批人 |
| P1 | 建立自动健康检查 | 每日运行配置验证，每周运行 12+7 场景测试，失败自动形成任务记录 | 系统维护人 |
| P1 | 启用独立真实模型适配器 | 安全配置凭证，完成一次只读测试，凭证缺失时仍能正确受阻 | 系统维护人 |
| P1 | 启用私有 Git 远端 | 安装 Git 或 GitHub Desktop，配置私有仓库、权限和恢复演练 | GitHub 管理员 |
| P2 | 建立运营指标看板 | 跟踪任务通过率、缺失字段率、审批耗时、MCP 失败率和知识更新时间 | AI 运营总监 |
