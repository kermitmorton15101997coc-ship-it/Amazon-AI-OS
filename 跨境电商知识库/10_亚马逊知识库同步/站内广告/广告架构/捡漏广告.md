捡漏广告
捡漏广告打法
自动广告 一个 asin 放在一个广告活动，固定竞价 0.1-0.3 。 0.1 无曝光点击就 0.05 往上调，调到正好有曝光点击为 1 。
手动广告
任何产品都可以使用捡漏广告，但一般对于成熟老品以及比较特别 ( 自带流量，差异化比较大等 ) 的新品效果会好许
多，一般的新品效果有好有坏，大家可以试着打一下。
一个 asin ，创建一个广告活动 , 一个广告活动下面
可以设置两组
一组：竞价 0.1-0.3 ，然后选择比较多的关键词 ( 后续可以陆续添加 ) 放入，选
择准确匹配。
二组：竞价 0.1-0.3 ，然后选择比较多的关键词放入，选择广泛匹
配。这两组如果关键词竞价 0.1 没有曝光与点击，可以 0.05 往上调
直到有点击与曝光为止。
多 SKU
方法 1
投放的商品：所有产品 / 同类产品 / 表现好的产品 / 表现差的产品
步骤 自动广告组 + 固定竞价 + 竞价 0.1-0.3 。
方法 2
投放的商品：所有产品 / 同类产品 / 表现好的产品 / 表现差的产品
步骤
自动广告 + 固定 / 只降低 + 竞价 0.02-0.1 ；
Bid+: 搜索页顶部 / 商品页面 400%-900 。
方法  3
投放的商品：所有产品 / 同类产品 / 表现好的产品 / 表现差的产品
步骤 自动广告 + 动态竞价 + 竞价 0.02-0.1 。
方法  4
投放的商品：品牌店主页产品 / 细分小页
步骤 步骤品牌广告 + 商品定位 / 类目投放 + 竞价 0.1-0.3 。
单 SKU
方法 1
自动广告 + 固定竞价 + 竞价 0.02-0.05 ；
Bid+: 搜索页顶部 / 商品页面 400%-900% 。
方法  2
自动广告 + 动态竞价 + 竞价 0.02-0.03;
Bid+: 搜索页顶部 / 商品页面 1 倍 -9 倍
展示广告 + 商品类目 + 竞价 0.1-0.3
方法  3 展示广告 + 商品类目 + 竞价 0.1-0.3
漏斗型打法
筛选类广告：自动、广泛、词组
同一个产品，这 3 种类型均单独建立广告活动，一个广告活动仅一个产品，广告出价可以是
推荐价格，也可以比推荐价格稍高。
广泛、词组类的广告关键词可以来源于添加关键词那里的推荐词，也可以用第三方关键词软件
推荐的相关词，还可以使用 asin 反查出来的词。
新建这 3 类广告后， 3-5 天可以调整出价，一般看点击， 10-20 次点击不出单的，往下调价，幅度一般为
15-20% ，只有几个点击的，出价调高 10% 左右，如果没有曝光的，批量设置出价调高 20% 左右。在调
整价格的同时，仍然需要新增关键词，这时你会发现，系统推荐的关键词会慢慢增加一些，表明 listing
的关键词广度更广了一些。广泛的添加关键词数量一般多一些，我这边一般是 200 多到 700 多个，词组
的关键词就会少一些，一般大部分来自于系统推荐词，一般也有 100 多到 200 多个。这些数据供参考借
鉴。
否定
因为这 3 类广告会出现一些不相关的一些词，所以需要每个月做几次否定，包括词组否定和
精准否定。
在调整出价和增添关键词的同时，你会发现有些客户点击关键词出单了，现在需要把出单的关键词单独摘出
来，然后去掉 ACOS 很高的出单词，再去掉曝光量和点击量都低于 10 的出单词，剩下的就是往精准广告添加的
关键词了
漏斗出口：精准
把筛选类 3 种广告的出单词放入精准广告
精准广告的出价为：筛选类广告出单词中每次点击费用  (CPC)(CNY) 加 0.1-0.2 左右；
在广告活动设置里面，搜索结果顶部（首页）这一项设定为 50-100% ，建议先从 50% 做起。
调整节奏：仍然按照点击次数来调整出价，一般来说， 10-20 次点击没有出单的，下调出价 20% 左右，点击次数
只有几次的，上调 15% 左右，没有曝光的，上调 20% 左右，有曝光没点击的先不动。关键词的 ACOS 有不理想
的，降低出价，降低百分比自己把握， ACOS 很低的关键词，在前台搜索下，看看位置在哪里，可以增加一些出
价观察下效果。
否定：把筛选类广告的出单词拿到精准后，筛选类广告那边并不需要做精准否定，不用担心两下互相竞争问题。
思路：因为精准广告里面的关键词都是筛选类广告出过单的词，用顶部出价百分比的方法，如果精准广告里面再次
出单，就会很容易锁定搜索结果顶部位置，如果 ACOS 合适的话，容易拉升同一个关键词的自然权重。另外，其实
每个 listing 都是有个性的，你所看重的类目非常相关的大词未必会出单，这种大词可能需要点击四五十次才能成交
一个，是非常得不偿失的，所以这种行业大词要不就不要放精准广告里面，要不就是出价非常低，尽量维持一个 10-
20 次点击会有一个订单的平衡线。你会发现筛选过来的精准关键词未必都是行业大词，但是，他们是你这个 listing
能出单的个性词，所以用调整出价的方法精心维护好这些词，会得到非常理想的效果。
调整出价的周期
一般是 7-15 天的时间作为出价调整的周期，来维持一个 10-20 次点击出一单的结果
适用范围：绝大部分 listing ，前提是 listing 做的比较理想的情况下
