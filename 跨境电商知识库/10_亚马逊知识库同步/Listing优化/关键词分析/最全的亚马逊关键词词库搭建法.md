竞品库挖掘法
竞品库挖掘法通常是在亚马逊寻找和你要上新的
产品同类和关联的 ASIN 库，进而通过工具去挖掘
这些 ASIN 的所有流量来源词。
同类 ASIN 是指与你要上新的产品有着高度相似属
性 / 功能 / 外观 / 设计 / 颜色 / 规格的产品，而关联
ASIN 是指与你要上新的产品有着高度关联的同级
类目 / 上级类目 / 用户人群 / 使用场景的产品。
  上下游产品类目是指不局限于和上新产品 ( 源产
品 ) 最相关的产品类目，还可以从上下游产品类目
中记录有着高度重合用户人群 / 重合使用场景 / 的
产品作为关联 ASIN 库。
实操步骤
 步骤一：在卖家精灵的关键词反查中输入竞品库
中的 ASIN ，并页面下方的点击 “ 查看所有变体流
量词 ” 工具按钮
 步骤二：在点击 “ 查看所有变体流量词 ” 工具按钮
跳转到拓展流量词面板
步骤三：在拓展流量词面板点击下方的 “ 全部加
入词库 ” 按钮，将竞品的所有关键词全部加入关
键词词库中
步骤四：重复上述的动作，将竞品库中所有 ASIN
的流量词迁移记录到关键词词库
ABA 数据挖掘法
 ABA 数据挖掘法是基于竞品种子库，通过竞品种
子库的 ASIN ，可以通过亚马逊后台或者卖家精灵
的 “ABA 数据选品 ” 工具面板，将 ABA 关键词数据
全部加入词库

AC 词分级
通常分级关键词词海库的方法选取的都是 1-2 种方
式来做，如果你想要兼顾以上提到的所有方法来
做分级，大概率是行不通的，很难有既符合这样
又符合那样的交叉重合关键词
关于分级区间数值的取值，如搜索量区间多少为
一级，购买率区间多少为一级，我认为没有固定
的标准，可结合词库中想要看的维度下的关键词
数据低值、中位数均值、高值去做分级区间的判
断

亚马逊的检索机器对于你的产品标签认知也可能

搭建否词库最常见的来源之一是在你上新产品后
打开亚马逊广告界面，创建广告活动，通过输入
变体下的所有 ASIN ，查看系统推荐的广告词，提
前将系统推荐的不相关的词记录到否定词库中，
在未来开设的广告活动中提前否定这些词

相关性
验证筛选后的关键词词海库的相关性，需要我们
手动的通过关键词去通过亚马逊的搜索结果框查

竞争性
验证筛选后的关键词词海库的竞争度，最常见的
维度是参考 PPC 竞价，根据上新产品的利润情
况，测算在能接受的利润下平均点击出单次数下
的 CPC 区间范围，根据 CPC 区间范围判断该词是
否在理想的区间范围内，可以借助卖家精灵的
PPC 竞价做出筛选
敏感禁止性
验证筛选后的关键词词海库的敏感禁止性，一旦
我们埋词亚马逊的敏感禁止词，我们的账号就会
收到商品违规警告
确认关键词推广周期顺序
推词
第一点是参考竞品库中流量占比高的词首先推
词，可借助卖家精灵的 ” 关键词反查 “ 工具查看
第二点是参考竞品库中出单的词首先推词，可借
助卖家精灵的 ” 出单词反查 “ 工具查看
埋词
  最常见的埋词在标题、五点描述、后台搜索
词、 A+ 的 ALT 词、视频的 ALT 词、品牌故事的
ALT 词、上传表格中可布局文案信息的相关列属
性例如 COLOR NAME 、 TEAM NAME 、 SIZE 
NAME 、视觉文案词呈现等
