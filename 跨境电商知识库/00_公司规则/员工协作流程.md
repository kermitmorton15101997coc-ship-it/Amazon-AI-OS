# 员工协作流程

## 通用任务流

`提出任务 -> 任务主账本建档 -> 安全与范围检查 -> 读取知识库与数据 -> Agent 分析 -> 主管/老板审批 -> 人工执行 -> 结果监控 -> 复盘回写`

## 岗位分工

| 岗位 | 主要职责 | 默认交付 |
|---|---|---|
| 老板 | 看结果、审批关键资源、做经营决策 | 日报、周报、异常预警、审批结论 |
| 运营主管 | 维护规则、复核输出、创建任务模板 | SOP、复盘、任务模板、审批记录 |
| 运营助理 | 执行选品、Listing、Review类任务 | 初筛报告、Listing草稿、VOC摘要 |
| 广告专员 | 分析广告报表与搜索词 | ACOS/TACOS诊断、预算建议、否词建议 |
| 客服 | 处理买家消息与售后问题 | 合规回复草稿、售后问题归因 |
| 采购/供应链 | 跟进库存、补货、供应商交期 | 补货建议、断货风险、供应商记录 |

## 交付要求

- 每个任务必须写明目标、数据来源、缺失字段、风险等级和人工复核人。
- 中高风险任务未审批不得进入执行准备或测试中。
- 执行后必须记录基线、结果、偏差、停止条件和知识回写位置。
