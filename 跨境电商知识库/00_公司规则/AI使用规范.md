# AI使用规范

## 基本原则

- Amazon-AI-OS 第一版采用“AI分析 -> 人工审核 -> 人工执行”。
- Codex 与专项 Agent 只输出分析、建议、草稿、检查清单和执行方案。
- 涉及预算、补货、付款、账号、申诉、合规、侵权和对外发布时，必须进入审批。
- 所有结论必须标注数据来源、缺失字段、置信度和人工复核人。

## 禁止自动执行

- 真实预算变更
- 付款
- 补货下单
- 亚马逊后台发布
- 申诉提交
- 账号与权限操作
- 客服消息直接发送

## 安全边界

- 隔离黑帽资料不得进入日常检索、业务分析或 Agent 输出。
- 命中违规用途时，只能用于合规审计、风险识别、删除处置、反作弊教育、拒绝说明或安全替代建议。
- 卖家精灵 MCP 无返回或字段缺失时，必须标注缺失，不得凭经验补齐。
- 店铺内部最新数据优先于外部估算和历史培训资料。
