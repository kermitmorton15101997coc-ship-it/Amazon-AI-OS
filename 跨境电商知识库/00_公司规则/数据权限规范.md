# 数据权限规范

## 第一版权限模型

采用“公司私有 GitHub 仓库 + 目录隔离 + 审批门禁”。

| 角色 | 可读范围 | 可编辑范围 | 可调用 Agent | 必须审批 |
|---|---|---|---|---|
| 老板 | 全部合规资料 | 审批记录、经营决策备注 | CEO经营决策Agent、运营总控相关 Agent | 仓库成员、权限、预算、新品、补货、账号 |
| 运营主管 | 除隔离资料外的大部分资料 | SOP、任务模板、Agent提示词、复盘 | 运营总控Agent、全部业务 Agent | SOP变更、Agent提示词变更、任务模板变更 |
| 运营助理 | 选品、Listing、Review、项目任务 | 任务记录、选品与Listing草稿 | 亚马逊选品专家Agent、Listing优化Agent、Review分析Agent | 新品立项、Listing发布、核心规则变更 |
| 广告专员 | 广告体系、关键词、广告报表、相关Listing资料 | 广告复盘、搜索词分析、优化建议 | 广告优化Agent、搜索词分析Agent、ACOS异常诊断Agent | 预算调整、活动结构大改、停投放量动作 |
| 客服 | 客服SOP、订单状态、评价规则、产品共性问题 | 客服草稿、售后复盘 | 客服合规回复Agent、差评预警Agent、退货处理Agent | 敏感回复、补偿承诺、差评相关处理 |
| 采购/供应链 | 库存、销量、补货、供应商交期、产品资料 | 库存复盘、补货建议、供应商跟进记录 | 库存补货Agent、断货风险Agent、产品开发Agent | 补货下单、付款、供应商关键承诺 |

## 目录隔离建议

- 客服账号不访问利润、成本、供应链全量数据。
- 广告专员不直接修改预算执行表，只能提交建议。
- 运营助理不能修改 `00_公司规则`、核心 SOP 和机器配置。
- 采购/供应链不能访问广告利润全量数据，除非老板或运营主管审批。

## 执行记录

所有中高风险任务必须在 [[../08_项目管理/任务主账本/_目录|任务主账本]] 中记录审批人、审批结论、执行条件和复盘结果。
