# 岗位注册覆盖对照表

## 使用规则

本表用于把业务岗位矩阵和机器配置中的 `agent_registry` 对齐。正式调度只能调用已注册 Agent；未注册的细分岗位必须由已注册 Agent 承接，并在任务分派中写明职责边界。

状态定义：

- `已注册独立 Agent`：可在 `.codex/amazon-ai-os.config.json` 的 `agent_registry` 中直接调度。
- `已合并承接`：不作为独立 Agent 调度，由表中指定 Agent 按子职责处理。
- `暂未上线`：当前只作为业务需求记录，不进入正式调度。

## 调度约束

- `暂未上线` 岗位不得出现在正式 `routing_rules` 中。
- `已合并承接` 岗位必须在任务分派表的“负责问题”字段写清子职责。
- 涉及利润、现金、预算、补货、账号、申诉、合规与侵权事项，必须保留人工复核字段。
- 若未来将细分岗位升级为独立 Agent，必须同步更新 `.codex/amazon-ai-os.config.json`、本表、路由表和验收用例。
