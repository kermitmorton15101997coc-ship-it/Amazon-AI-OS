# 本地环境说明

## 当前入口

- 工作区根目录：`D:/亚马逊CODEX独立团/Amazon-AI-OS`
- 默认 Vault：`D:/亚马逊CODEX独立团/Amazon-AI-OS/跨境电商知识库`
- 正式配置：`.codex/amazon-ai-os.config.json`
- 候选配置：`跨境电商知识库/09_AI智能体/amazon-ai-os.config.v2.json`

## Python

当前普通 `python` 命令可能不可用。Amazon-AI-OS 脚本统一通过 PowerShell 包装入口运行；包装脚本会优先寻找系统 Python，找不到时使用 Codex bundled Python：

`%USERPROFILE%/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`

因此，普通 `python` 不存在不视为闭环失败；只要 PowerShell 包装脚本可运行即可。

## Git

当前环境未检测到系统级 `git` 命令。GitHub 远端创建、首次推送和多电脑协同建议通过以下任一方式完成：

- 安装 Git 或 GitHub Desktop 后再执行本地 Git 操作。
- 由 GitHub 管理员在网页端创建私有仓库并配置权限。

## OpenAI 真实适配器

独立调度层真实模型适配器需要：

- `OPENAI_API_KEY`
- 可用网络能力
- 可选：`AMAZON_AI_OS_MODEL` 覆盖默认模型

缺少凭证或网络时，真实适配器必须进入 `受阻`，不得冒充真实专项智能体结论。

## 飞书

飞书 MCP 当前处于“已设计接入，待本机凭证与用户授权”状态。本机验收脚本检查以下变量：

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- `LARK_DOMAIN`
- `LARK_TOOLS`
- `LARK_TOKEN_MODE`
- `FEISHU_OAUTH_SCOPE`

其中 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` 必须使用安全的用户级环境变量或密码管理器配置，不得写入仓库。飞书内容进入长期知识层前，必须先同步或摘录为 Obsidian Markdown，并写入 [[../08_项目管理/飞书同步日志]]。

## 嵌套副本

`Amazon-AI-OS/` 是镜像/备份副本，不作为默认读取、验证、同步或写回入口。默认事实源始终是根目录 `.codex` 与根目录 `跨境电商知识库`。
