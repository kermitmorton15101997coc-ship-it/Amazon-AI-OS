# 本地环境说明

## 当前入口

- 正式工作区：GitHub 私有仓库 `jinyanjie321-commits/Amazon-AI-OS`
- 默认 Vault：仓库内 `跨境电商知识库`
- 正式配置：`.codex/amazon-ai-os.config.json`
- 候选配置：`跨境电商知识库/09_AI智能体/amazon-ai-os.config.v2.json`

## Python

当前普通 `python` 命令可能不可用。Amazon-AI-OS 脚本统一通过 PowerShell 包装入口运行；包装脚本会优先寻找系统 Python，找不到时使用 Codex bundled Python：

`%USERPROFILE%/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`

因此，普通 `python` 不存在不视为闭环失败；只要 PowerShell 包装脚本可运行即可。

## Git

Windows 多电脑部署统一使用正式私有仓库。Git 可来自系统安装或 GitHub Desktop 内置 Git；初始化和验收脚本会自动发现两者。

## OpenAI 真实适配器

独立调度层真实模型适配器需要：

- `OPENAI_API_KEY`
- 可用网络能力
- 可选：`AMAZON_AI_OS_MODEL` 覆盖默认模型

缺少凭证或网络时，真实适配器必须进入 `受阻`，不得冒充真实专项智能体结论。

## 飞书

飞书 MCP 基础变量已配置，但 `FEISHU_OAUTH_SCOPE` 当前缺失，知识库读取仍待用户访问令牌或知识空间授权。飞书内容进入长期知识层前，必须先同步或摘录为 Obsidian Markdown，并写入 [[../08_项目管理/飞书同步日志]]。

## 多电脑部署

- 初始化入口：`scripts/initialize_windows.ps1`
- 验收入口：`scripts/acceptance_test_windows.ps1`
- 完整合规 Vault 通过 `scripts/export_compliant_vault.ps1` 生成 AES-256 加密离线包。
- 每位员工独立配置飞书、卖家精灵和可选 OpenAI 凭据；凭据和本机授权状态不进入仓库或迁移包。
