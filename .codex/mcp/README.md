## 飞书启用条件

飞书环境变量已经存在，但历史日志显示应用身份看不到知识空间，搜索 Wiki 节点需要用户访问令牌或对应知识库授权。

启用后，飞书只作为上游来源；进入长期知识层前必须同步为 Obsidian Markdown，并写入同步日志。

## 卖家精灵使用条件

卖家精灵只用于外部市场数据，不替代店铺后台、广告报表、库存表、成本表和人工判断。

所有输出必须标明数据来源、工具名、缺失字段和需要人工复核的内部数据。
